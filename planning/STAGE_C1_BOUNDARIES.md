# Stage C1 boundaries

`planning/stage_c1_plan.yaml` is the binding scope and budget after its SHA-256
freeze is recorded. Its caps are not self-amendable; an exhausted cap stops the
affected work and any dependent item. Stage C0's third-round exception is
historical and has no force here. Earlier Stage A–C0 artifacts and acceptance
reports remain unchanged.

C1-01 builds exactly nine `PUBLIC_CALIBRATION` cases: two T1 leakage, two T2
concept replications, and five T3 (two null, cost, decay, one composite A-share
execution trap). The T2 original definitions must be read from the local
original paper PDFs and frozen in `ReferenceDefinitionManifest`s before their
oracles exist. An unavailable or unreadable original yields
`BLOCKED_REFERENCE_NOT_VERIFIED`, not a guessed definition. Each generator,
oracle, perturbation, rejection layer and failed output remains inspectable.
Public exposure is recorded; public cases can never be promoted to a hidden
score. No hidden mechanism, seed or label is created in C1.

C1-02 inventories official documentation and, only if essential, a bounded
preregistered sample for PIT and historical-coverage feasibility. `DOCUMENTED`
means source documentation, never observed rows; `SAMPLE_VERIFIED` requires
actual small-sample artifacts. Unknown fields stay unknown. Data provenance is
separate from retrieval wrappers. D11/D12 remain deferred. No returns,
factor or strategy hypothesis is evaluated.

C1-03 can start only after separate C1-01 and C1-02 PASS evidence. It builds
four public prototypes, one per tier. T4 is a public development oracle
prototype, **not** a tenth calibration slot. The B2 runner permits one frozen
synthetic daily operation and cannot express a paired model benchmark; C1-03
may use existing canonical worker/ledger/critic/evaluator components with a
new public-only adapter, but may not alter or claim benchmark-grade sealed or
model-comparison behavior. Scripted positive, fabricated, refusal, malformed
and missing outputs test terminal denominators. No LLM provider is called.

An independent critic challenges oracle independence, paper fidelity,
baseline gaming, source-evidence levels, wrapper provenance, sample selection,
T4 slot count and deferred decisions. Any unresolved P0/P1 blocks C1 PASS.
Formal G4/G6 and D04B/D11/D12 stay blocked irrespective of public tests.
