# Stage C2 boundaries

The hash-frozen `stage_c2_plan.yaml` is binding. Exhausted repair, critic,
test, source, or API budgets stop the affected work and its dependents. No
historical exception grants an automatic increase. C1 evidence and artifacts
are inputs and remain unchanged.

C2-01 uses the existing Task/Condition/Family/Run/Experiment/Budget/Trace,
Worker, Candidate, Evidence, Critic, Evaluator, EvalResult and RunManifest
owners. Before changing a canonical contract to accommodate public fixtures,
it records the ownership conflict and the smallest owner-level resolution.
Public fixtures cannot produce scientific strategy trials, official scores,
G4/G6 PASS, or a second Candidate/Evidence/EvalResult truth.

C2-02 preregisters IDs, dates, events and query counts before seeing sample
responses. Source documentation is not sample evidence; successful API access
is not a license grant. Unknown publication/availability/revision clocks stay
unknown, especially for date-only data and delisted entities. Only a bounded
sample is allowed, never a production Benchmark dataset.

C2-03 may audit historical rule documents early. Its empirical execution and
capacity work requires a usable C2-02 candidate. Daily bars cannot establish
queue position or guaranteed fills. Direct rule fees and uncertain market
costs remain separate. Rule versions carry effective dates; D12 is not frozen.

C2-04 starts only when C2-02 and C2-03 provide enough observed geometry for a
named task family. A closed gate produces an explicit `NOT_STARTED_GATE_CLOSED`
record, not simulated market power or invented parameter values. Even a study
can only propose D04B values for a later user decision.

An independent critic challenges all four workstreams. Unresolved P0/P1 blocks
Stage C2 PASS. W09 remains `SYNTHETIC_MOCK`, G6 remains `BLOCKED`, and official
Benchmark, hidden pack, real models, model comparison and strategy search remain
out of scope. Stop at `stage_c2_acceptance.yaml`.
